# 일상 블로그 작성기 개발계획서

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 일상 블로그 작성기 (가칭: 하루기록) |
| 목적 | 사진, 시간, 글, 기분, 날씨, 장소를 한곳에 기록하는 개인 일상 블로그 |
| 사용자 | 작성자: 본인 1명 (Google 로그인) / 독자: 누구나 (읽기 전용) |
| 디자인 | 따뜻한 다이어리 느낌 (베이지 톤, 종이 질감, 손글씨 느낌의 제목 폰트) |

## 2. 기술 스택

| 구분 | 기술 |
|---|---|
| Frontend | Next.js (App Router), TypeScript, Tailwind CSS |
| 인증 | Firebase Authentication (Google 로그인) |
| 데이터베이스 | Cloud Firestore |
| 사진 저장 | Firebase Storage (Blaze 플랜) — **보류**: 결제 계정 없이 진행하기로 해서 사진 업로드는 나중에 결정 |
| 코드 관리 | GitHub |
| 배포 | Vercel (GitHub 연동으로 push 시 자동 배포) |

## 3. 기능 목록

### 3.1 기록 작성 (작성자만)
- 제목, 본문
- 사진 여러 장 업로드 (업로드 전 브라우저에서 자동 리사이즈)
- 날짜/시간 (기본값: 현재 시각, 직접 수정 가능)
- 기분: 이모지 선택 (😊 😐 😢 😡 😴 🥰 등)
- 날씨: 아이콘 직접 선택 (☀️ 맑음, ⛅ 구름, ☁️ 흐림, 🌧️ 비, ❄️ 눈)
- 장소: 텍스트 입력
- 카테고리/태그: 여러 개 입력 (예: 맛집, 여행, 운동)
- 수정, 삭제

### 3.2 보기 화면 (누구나)
- **타임라인**: 최신 글부터 날짜순 카드 피드
- **캘린더**: 월 달력에 기록 있는 날 표시, 날짜 클릭 시 그날 기록 목록
- **사진 갤러리**: 모든 사진을 격자로 보기, 클릭 시 해당 글로 이동
- **글 상세**: 사진, 본문, 기분/날씨/장소/태그 표시
- **태그별 모아보기**: 태그 클릭 시 같은 태그 글 목록

### 3.3 인증
- Google 로그인
- 지정된 작성자 계정(본인 UID)만 쓰기/수정/삭제 가능
- 로그인하지 않은 방문자는 읽기만 가능

## 4. 화면 구조 (페이지)

| 경로 | 화면 | 권한 |
|---|---|---|
| `/` | 타임라인 | 누구나 |
| `/calendar` | 캘린더 | 누구나 |
| `/gallery` | 사진 갤러리 | 누구나 |
| `/posts/[id]` | 글 상세 | 누구나 |
| `/tags/[tag]` | 태그별 목록 | 누구나 |
| `/write` | 새 기록 작성 | 작성자 |
| `/posts/[id]/edit` | 기록 수정 | 작성자 |
| `/login` | 로그인 | 누구나 |

## 5. 데이터 구조

### Firestore: `posts` 컬렉션
```
posts/{postId}
  title: string
  content: string
  photos: { url: string, path: string }[]
  recordedAt: Timestamp      // 기록한 날짜/시간
  mood: string               // 이모지
  weather: string            // sunny | partly | cloudy | rain | snow
  place: string
  tags: string[]
  authorId: string
  createdAt: Timestamp
  updatedAt: Timestamp
```

### Storage
```
photos/{postId}/{파일명}
```

### 보안 규칙
- Firestore `posts`: 읽기는 누구나, 쓰기는 `request.auth.uid == 작성자 UID`일 때만
- Storage `photos/`: 읽기는 누구나, 쓰기는 작성자만, 이미지 파일·10MB 이하만 허용

## 6. 개발 및 배포 단계 (최소 3회 배포)

| 단계 | 내용 | 배포 |
|---|---|---|
| 0. 환경 준비 | GitHub 저장소 생성, Firebase 프로젝트 생성(Auth/Firestore/Storage), Vercel 프로젝트 연결, 환경변수 등록 | - |
| 1. 기본 뼈대 | Next.js 프로젝트 생성, 다이어리 디자인 레이아웃, 상단 메뉴(타임라인/캘린더/갤러리) | **1차 배포** |
| 2. 핵심 기능 | Google 로그인, 기록 작성·수정·삭제(글+날짜/시간), 타임라인, 글 상세, 보안 규칙 적용 (사진은 보류) | **2차 배포** |
| 3. 부가 정보 | 기분/날씨/장소/태그 입력과 표시, 태그별 모아보기 | **3차 배포** |
| 4. 보기 확장 | 캘린더 보기, 사진 갤러리 | **4차 배포** |
| 5. 마무리 | 모바일 화면 다듬기, 빈 화면 안내, 로딩 표시 | **5차 배포** |

각 단계가 끝나면 GitHub에 push하고, Vercel이 자동 배포해요. 배포마다 Vercel Deployments 화면과 로그를 캡처해 제출 자료로 모아요.
